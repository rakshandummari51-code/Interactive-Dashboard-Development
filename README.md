# Interactive Dashboard Development

## Overview
This project presents an interactive dashboard for analyzing monthly sales and profit data using Python and Streamlit. The dashboard helps visualize business performance trends and key insights for better decision-making.

## Features
- Interactive sales dashboard
- Monthly sales trend visualization
- Profit analysis using charts
- Business performance insights
- Real-time dashboard view in browser

## Technologies Used
- Python
- Pandas
- Streamlit
